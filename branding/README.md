# Brain Keyboard

Original vector logo: mint `#75F0C2` brain and keyboard on navy `#101A31`.

- `brain-keyboard-icon.svg`: editable square brand mark.
- `brain-keyboard-logo.svg`: editable horizontal wordmark.
- `brain-keyboard-icon-512.png` and `brain-keyboard-icon-1024.png`: transparent-corner PNG exports.
- `brain-keyboard-logo.png`: transparent horizontal wordmark export.
- `render-brand.ps1`: reproducible Windows PNG renderer using the shared path data.

Android uses native vector drawables with adaptive backgrounds/foregrounds, plus a monochrome resource for Android 13 themed icons. The app package/application ID stays unchanged so installation updates the existing app and retains settings.
